## Ark: Iam v0.3.0

- **BREAKING** explicit feature switches and GET /me (#168) (295a8a712d927da32f6281e0fc56406224c6a42c)
  Password, TwoFactor, Tokens, Permissions, Provider,
password.Builder.Reset, account.Builder.Verification and
permission.Builder.Management take enabled as their first argument.

* feat(iam): ignore settings whose dependency is off

Registration without Users.Create, SignUp without Create and built-in registration without Reset no longer fail construction. Each is ignored with one slog warning naming the setting and the reason.

* feat(iam): add GET /me

Builder.Me turns on GET /me. MeBuilder chooses the user projection, roles and permissions, two-factor state and login details.

* docs(iam): update guides for feature switches and /me
