* feat(core)!: absolute times and one duration in MCP diagnostic tools

Diagnostic tools now emit absolute RFC 3339 times and plain numbers only.
The CLI adds the relative part ("2026-11-23 10:00:01 (5s ago)") and
readable units (12.5ms, 1.2 MB) when it prints text on a terminal.

CLI renderer: relative timestamps against an injectable clock
(Style.Now, Environment.Now, TextAt), "`<name>_ms`" and "`<name>_bytes`"
numbers in readable units, flat objects as key=value table cells, and
compatibility with servers that still send age, next_in, duration strings
or has_more. Follow drains a page flagged truncated or has_more at once.
