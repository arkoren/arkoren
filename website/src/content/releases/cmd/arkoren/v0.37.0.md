## CLI v0.37.0

- **BREAKING** consistent results, errors, next steps and checks (#189) (6a8ac0ff6ceffab3fc3da9db2e9d05d6fc0d5ca8)
  next_steps entries are objects instead of strings; the
error document gains a top-level next_steps and always has error.type, and
error.hint is removed; unreachable, not-configured, conflict and usage
failures changed type, message and, for file conflicts, exit code (2 to 1);
check reports problems (rule, path, line, message) instead of violations;
key check reports ok, kind and problems and exits 1 on invalid material;
certificate check reports ok and problems for invalid material instead of
an error; skills status reports ok and problems and exits 1 when not ok;
skills install and update drop written_files, removed_files,
conflict_count and the per-skill conflicts list; the trust stderr document
is {"warnings": [...]} instead of {"warning": {...}}; the certificate trust
notice moved from next_steps to warnings; key results use kind instead of
category.
