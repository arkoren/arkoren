- add ark/access (#122) (f474cdf6c935cd9f13173bf4690d56c421ba00fe)

- **BREAKING** finish Apple form_post login in a top-level GET (#124) (80571b99e6e4d64203284177b44fdd97051cd9a8)
  form_post callbacks (Apple) must be mounted for both GET and
POST; a GET carrying a code is rejected. RedirectURL of a form_post client must

- document arks in their own Arks section (#127) (0a3cfc7983f9f32bc85a69417c40f6e35852826f)


- add Guard.LockedOut (#129) (71b8e64b36217e51d75e4c1bb7b4c531417fc9a4)


- **BREAKING** close high-severity security gaps in the access facade (#128) (ad2f0b999e7640f9b6073361af63d3a7fe9153a6)
  Builder.RevokeTokensOnPasswordChange is removed. A
password change and enabling two-factor now revoke personal tokens by
default; call Builder.KeepPersonalTokens to keep them. Callbacks passed to
Builder.Guard and Builder.Session can no longer override the session
lifetime or handle, the guard's event bus or the client address.

* fix(access): count second-factor lockouts through Guard.LockedOut

The password login asks the guard after a correct password and keeps the
attempt counted while the user is locked out, failing closed when the
lockout cannot be read. This replaces the private event bus and the
CountLockout marker: events stay optional notifications.

* fix(access)!: require application/json on POST, PUT and PATCH routes

Every POST, PUT and PATCH handler rejects another or a missing media type
with 415, including routes that read no body, so a cross-site HTML form
cannot reach any state-changing route. DELETE and the provider routes are
exempt. The guides show mounting core's csrf.Middleware next to
iam.Middleware(), which the facade does not add.
